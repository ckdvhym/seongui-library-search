성의고 도서관 통합 관리 V8.6

장서 동기화부터 메타데이터 구축·검색 인덱스 생성까지 한 화면에서 관리합니다. 작업 결과는 배치마다 서버에 저장되어 중간에 닫혀도 이어서 진행할 수 있습니다.

1. 관리자 암호

암호는 이 화면에서 API 요청에만 사용하며 브라우저에 저장하지 않습니다.

현재 8,050종 기본 카탈로그와 학교 설정을 Vercel Blob에 저장합니다. 같은 파일을 다시 실행해도 덮어쓰기 방식이라 중복 저장되지 않습니다.

4. 국립중앙도서관 소장자료 API 연결 (코드 V5.4)

Vercel에 설정한 NLK_API_KEY를 서버에서만 사용해 ISBN 서지정보 API를 확인합니다. 인증키는 브라우저에 노출하지 않습니다.

아직 확인하지 않았습니다.
학교 로고 설정 (선택)

로고를 등록하면 학생용 첫 화면과 주제검색 화면의 ‘성의고등학교 도서관’ 왼쪽에 작게 표시됩니다. 등록하지 않으면 지금처럼 글자만 보여서 깔끔하게 유지됩니다.

현재 로고를 확인하려면 관리자 암호 입력 후 ‘로고 설정 불러오기’를 눌러 주세요.
로고는 아직 확인하지 않았습니다.
5. 장서자료 업데이트 (운영 V8.6)

DLS에서 반출한 엑셀(.xlsx)을 올리면 기존 서버 장서와 먼저 비교합니다. 비교만 할 때는 데이터가 바뀌지 않습니다.

아직 엑셀을 비교하지 않았습니다.
6. 통합 검색 데이터 구축 (운영 V8.6)

YES24 상세정보를 장서별로 수집하고, 필요한 경우 국립중앙도서관으로 보완한 뒤 주제·장르·키워드 프로필과 학생용 검색 인덱스를 만듭니다. 한 번 시작하면 배치마다 서버에 저장되므로 중간에 창을 닫아도 다음에 이어서 할 수 있습니다.
