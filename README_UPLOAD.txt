성의고등학교 도서관 주제검색 V8.0 - 자연어·학과검색 안정화 1단계

변경사항
- 학과/전공/진학/연계 표현을 검색 주제가 아닌 검색 목적 표현으로 처리
- 경제학, 간호학, 컴퓨터과학, 생명공학 등 주요 전공군을 기존 인덱스에서 의미 확장
- 그 밖의 학과는 복잡한 자연어 검색 때 기존 Gemini 1회 해석 안에서 의미 확장
- 책별 Gemini 호출 없음 / 전체 메타데이터 재수집 없음
- 검색 결과 화면의 상단 '주제 검색' 제목을 클릭하면 현재 검색 결과 초기화
- V7.9의 침묵의 봄 메타데이터 복구 유지

배포
1. GitHub에 전체 파일 덮어쓰기
2. Vercel Ready 확인
3. 관리자 재구축하지 않음
4. 아래 검색만 우선 확인
   경제학과 진학을 위한 책
   간호학과 관련 된 책
   간호학과 연계 책
   컴퓨터학과 관련 된 책
   생명공학과와 연계된 책

주의: 검색 인덱스 V7.7 표시는 저장 인덱스 버전이며 정상입니다.
