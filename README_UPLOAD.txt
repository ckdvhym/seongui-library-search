V7.7 주요 변경
- '환경과 관련 있는 소설'처럼 조사(과/와 등)가 붙은 검색어를 필수 문자열로 잘못 인식하던 문제 수정
- 소설/시/에세이가 명시된 경우 '문학·글쓰기' 일반 주제의 중복 엄격 필터 제거
- 한국 고전문학 인식 보강(구운몽·홍길동전·춘향전 등, 고전 작가·총서 분류 보완)
- 주제검색 첫 화면의 '주제 검색' 제목을 중앙의 주요 제목으로 이동하고 검색창과 공간감 조정
- 검색 후에는 기존처럼 상단 고정 검색바 유지
- DLS 버튼 명칭을 '우리 도서관 도서 검색'으로 통일
- 목차를 세로 항목으로 더 잘 분리하도록 표시 개선
- YES24 상세조회 응답 형식이 조금 달라도 복구할 수 있도록 파서 보강
