성의고등학교 도서관 V8.3 - 의미검색·로맨스 장르 안정화

핵심 변경
1. 「힐링되는 소설」: 힐링이라는 동일 단어가 없어도 위로·회복·치유·희망·관계·새출발 등의 의미 근거로 검색합니다.
2. 「로맨스 소설」: 저장된 로맨스 태그만으로 통과시키지 않고 제목/책소개에서 실제 로맨스 근거를 한 번 더 확인합니다. 무협·모험소설의 부수적 연애 요소가 상위 결과를 차지하는 현상을 줄입니다.
3. 학교 배경 등 로컬에서 이미 의미를 해석한 검색은 Gemini를 다시 호출하지 않아 체감 속도와 호출량을 줄입니다.
4. 기존 학과검색·고전·추리·경제·컴퓨터·생명공학 검색 로직은 유지합니다.
5. 관리자 화면의 구축 버전 표시를 V8.3으로 맞췄습니다.

업로드
- 이 ZIP의 파일/폴더를 GitHub 저장소 루트에 그대로 덮어씁니다.
- Vercel이 Ready가 되면 관리자에서 「통합 검색 데이터 구축」을 한 번 실행합니다.
- 외부 메타데이터를 다시 수집하는 작업은 아닙니다.
