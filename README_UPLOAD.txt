성의고 도서관 V8.4 업로드 안내

1. ZIP을 풀어 GitHub 저장소의 같은 위치에 덮어씁니다.
2. Vercel이 Ready가 되면 검색 인덱스 재구축은 하지 않아도 됩니다.
   - 이번 버전은 검색 시점의 의미 판정 로직을 보강한 것이며, 기존 메타데이터/검색 인덱스를 그대로 사용합니다.
3. 확인할 검색어
   - 로맨스 소설
   - 따뜻한 로맨스 소설
   - 힐링되는 소설
   - 학교 배경 소설
4. 학교 로고(선택)
   - 관리자 페이지에서 관리자 암호 입력
   - '학교 로고 설정'에서 PNG/JPG/WebP 선택
   - '선택한 로고 저장' 클릭
   - 로고를 등록하지 않으면 학생용 화면은 기존처럼 글자만 표시됩니다.

V8.4 핵심
- 로맨스: 저장된 장르 태그 하나만으로 통과하지 않고 제목/책소개에서 로맨스 중심 근거 확인
- 힐링: 위로/회복/치유/희망 등 중심 근거가 있거나 따뜻함·성장·관계 의미가 충분할 때 통과
- 학교 배경: '배경'이라는 단어 자체를 책에 요구하지 않고, 실제 학교/교실/학교생활 근거를 확인
- 기존 학과/경제/컴퓨터/생명공학/추리 검색 구조는 유지
- 학교 로고는 코드에 고정하지 않고 관리자 페이지에서 선택적으로 저장
