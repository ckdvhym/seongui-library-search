성의고등학교 도서관 주제 검색 V7.9 - 메타데이터 연결 복구

이번 버전은 검색 알고리즘/검색 인덱스를 변경하지 않습니다.
따라서 관리자 페이지에서 통합 검색 데이터 재구축을 실행할 필요가 없습니다.

핵심 수정
- 상세정보 누락 시 현재 검색결과 ISBN으로 YES24 상세 조회
- ISBN 조회로 복구되지 않고 사용자가 책 제목을 정확히 검색한 경우에만 YES24 제목검색 1회 추가
- 제목검색 결과는 제목 완전 일치일 때만 자동 채택하여 오연결 방지
- 복구된 메타데이터는 기존 Blob 메타데이터 청크에 저장
- 일반 주제검색에서는 추가 제목검색을 하지 않아 속도와 API 호출량 보호
- 관리자 V7.7 표시는 '검색 인덱스 V7.7'이라고 명확히 표기

배포
GitHub 기존 파일을 이 폴더의 파일로 덮어씁니다.
Vercel 배포가 Ready가 되면 바로 '침묵의 봄'을 검색합니다.
재구축은 하지 않습니다.
