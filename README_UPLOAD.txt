V7.5 주요 변경
- ‘여수의 사랑’이 ‘수의사’로 잡히는 공백 제거 부분문자 오탐 차단
- 비문학 책 소개 속 ‘소설가’ 단어만으로 소설로 판정되던 문제 제거 (빅 히스토리 등)
- ‘고전 소설’과 ‘고전 한국 문학’을 구분하고 한국 고전문학 근거 보강
- 한국 고전소설/고전문학은 KDC, 책소개, 작품명 근거를 함께 사용
- 주제검색 첫 진입 시 빈 화면 대신 안내 패널 표시
- 검색 후에는 안내 패널을 숨기고 카드 결과에 집중
- 브라우저 뒤로가기로 이전 검색어와 결과를 복원
- 상단 ‘도서 검색’을 ‘소장·대출 확인’으로 변경
- 책 소개 / 목차 개별 펼침, 3~4열 카드, 더 보기 유지
