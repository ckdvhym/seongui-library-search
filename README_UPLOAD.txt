성의고등학교 도서관 V7.6 통합 안정화·디자인 개선본

업로드
- 이 폴더의 파일과 폴더를 기존 GitHub 저장소의 같은 위치에 덮어씁니다.
- Vercel 배포가 Ready가 되면 학생용 화면을 바로 확인할 수 있습니다.
- 이번 수정은 검색 실행 로직과 화면 중심이라 기존 8,050종 메타데이터를 다시 수집할 필요가 없습니다.
- 관리자에서 통합 구축을 다시 누르는 것은 필수가 아닙니다. 추후 검색 인덱스를 다시 만들 때부터 V7.6 기준이 적용됩니다.

V7.6 주요 변경
1. 첫 화면: 두 카드 전체가 클릭 영역. 불필요한 설명·버튼 삭제, 중앙 배치 개선
2. 주제검색 초기 화면: 설명을 한 문장으로 정리하고 검색창을 화면 중앙부에 자연스럽게 배치
3. 검색 후에는 상단 검색바 고정, '우리 학교 도서 검색' 버튼 표시
4. 검색 결과 카드 디자인은 V7.5 형태 유지
5. 상세 화면의 불필요한 '책 소개 보기' 버튼 삭제
6. 목차를 세로 항목형으로 정리해 읽기 쉽게 표시
7. 복본 청구기호는 대표값 하나만 표시하고 소장 권수 별도 표기
8. '고전 한국 문학' 검색 보정: 구운몽·홍길동전·춘향전 등 한국 고전 작품 근거를 별도 인정
9. '수의사'의 부분문자 오탐(예: 여수의 사랑) 방지
10. 기존 YES24 정보가 빠진 ISBN 도서는 상세정보 조회 시 YES24에서 1회 보완하여 표시
