성의고등학교 도서관 V9 통합업데이트 재검증본
기준: 기존 정상 운영관리개선 전체본에서 시작하여 필요한 변경만 병합

보존 확인
- 주제검색 첫 화면 추천목록 로딩/캐시
- 추천목록 상세 페이지 recommendations.html
- 학교 로고/행사 배너 설정 및 기존 저장 데이터 경로
- 로고 변경 이력
- 추천목록 관리자/순서/미소장 수서후보 연결
- 첫 화면/주제검색/도서검색/모바일 뒤로가기

이번 반영
- 근거 없는 인명형 검색 의미확장 방어(의심 인명은 고신뢰 판별 + 실제 장서 근거 우선)
- 검색 상세의 추천 이유에서 검색어 자체/일반 의미표현 제거
- 0건 검색 안내와 실제 관련주제 표시 상태 일치
- 검색 이용·수서: 기간조회, 검색어/횟수/최근검색/당시결과/다시검색
- 전체 장서 갱신 유지
- 일부 자료 수정/폐기 자료 삭제/미리보기/백업/직전 되돌리기
- 향후 전체 동기화 데이터에 등록번호별 소장 상세(items) 저장

검증
- 검색 회귀검사 35/35 PASS
- HTML 내 JavaScript 5개 화면 구문검사 PASS
- API/라우트 구문검사 PASS

[추천도서 첫 화면 안정화 추가 수정]

- 장서 검색 인덱스 재생성으로 bookId가 달라져도 ISBN/제목+저자 기준으로 자동 재연결
- home 추천 API가 빈 목록을 반환할 때 active 추천목록으로 한 번 더 복구 시도
- 추천목록 캐시는 유지하되 서버 최신 데이터로 갱신
