V8.8 검색 회귀보호 기준

핵심 원칙
- 특정 검색어를 고치기 위한 일회성 if 추가를 최소화한다.
- 사용자가 직접 지정한 자료형(소설/시/에세이), 장르, 문학권은 하드 조건으로 보존한다.
- 주제/감정/연관개념만 정확 → 관련 → 완화 순으로 넓힌다.
- 넓은 context 단어 하나만으로 엔터티 검색 결과에 들어오지 못한다.
- 짧은 단어의 부분문자열 오인을 막는다. (시집≠집, 운동≠돈, 방법≠법)
- Gemini는 필요한 검색어 해석에만 1회 사용하고, 책별 호출은 하지 않는다.

대표 보호 검색
- 환경과 관련 있는 소설
- 기후 위기 관련 소설
- 고전 소설 / 고전 한국 문학
- 일본문학 / 일본 문학
- 로맨스 / 따뜻한 로맨스 소설 / 슬픈 로맨스
- 힐링되는 소설 / 휴식 / 슬픈 책
- 가족 관련 시 / 가족 관련 시집 / 사랑 관련 시
- 단편 소설 / 학교 배경 소설
- 유교 / 공자 / 나치 / 성당 / 가톨릭
- 간호학과 / 컴퓨터학과 / 생명공학과 / 경제학과
